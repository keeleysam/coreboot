# BKHD 1264NP-4L-5G

The BKHD 1264NP-4L-5G is an Alder Lake-N (Intel N100) network appliance
motherboard, 120 mm x 120 mm, sold by BKHD in the G30W-1264NP-4L5G chassis.
It carries four Intel I226-V 2.5GbE ports, a combo M.2 Key-M 2280 slot, an
mPCIe slot, an M.2 Key-B 3052 WWAN slot with two SIM sockets, an ITE IT8625E
Super I/O and a single DDR5 SO-DIMM socket.

**WARNING:** BKHD sells several boards with similar names and different
layouts, and the same designs are resold under other brands, Topton among
them. This board is *not* the 1264NP-12-4L, which has an M.2 Key-E CNVi slot
in place of the WWAN slot and routes its NICs to different root ports. Do not
cross-flash between them.

## Required proprietary blobs

| Binary | Purpose | Required |
|--------|---------|----------|
| IFD | Intel Flash Descriptor | Required, keep the board's own |
| ME | Intel Management Engine | Required, keep the board's own |
| FSP-M, FSP-S | Alder Lake-N IoT FSP | Required, vendored in `3rdparty/fsp` |

The FSP is redistributable and is picked up automatically through
`FSP_TYPE_IOT`. The descriptor and ME are not shipped by coreboot: keep the
ones already on the board and flash only the BIOS region.

## Flashing

The board ships with an unlocked descriptor, so every region is readable and
writable from a booted OS and no external programmer is needed for normal
updates. Take a full-chip backup first, twice, and compare:

```
flashprog -p internal -r backup-1.rom
flashprog -p internal -r backup-2.rom
sha256sum backup-1.rom backup-2.rom
```

Then write the BIOS region only:

```
flashprog -p internal --ifd -i bios -w build/coreboot.rom -N
```

**Never write a complete image.** `board.fmd` describes the flash exactly as
the factory descriptor does, a 4 KiB descriptor, an ME region ending at
`0x413fff` and a 10 MiB BIOS region based at `0x600000`, so the BIOS region of
a coreboot image lines up with the BIOS region of the chip.

`flashrom` accepts the same arguments, but `flashprog` v1.3.0 or newer is
recommended for this hardware class.

The SPI flash is a soldered 16 MiB Winbond W25Q128 family part in SOIC-8.

## Serial console

Two 16550 ports are wired, both on the IT8625E:

* **COM1** at `0x3f8`, IRQ 4, brought out to the front-panel RJ45 console
  socket in the usual Cisco pinout.
* **COM2** at `0x2f8`, IRQ 3, on the internal `J_COM` header, selectable
  between RS-232 and RS-485 by the `JCOMP2` jumper.

`DRIVERS_UART_8250IO` is selected and COM1 is enabled in the bootblock, so the
console is live from the start of the boot.

## Working

Tested against the stock firmware and reproduced under coreboot except where
noted.

* All four Intel I226-V 2.5GbE ports
* M.2 Key-M 2280, both as NVMe and as M.2 SATA
* SATA connector
* mPCIe slot, PCIe and USB 2.0
* All six USB-A ports
* Intel PTT (fTPM 2.0) through the CRB interface
* Serial console on COM1

## Not yet supported

* **Graphics.** coreboot performs no display initialization. Every Alder Lake
  FSP in `3rdparty/fsp` ships without a GOP driver, and libgfxinit has no Alder
  Lake support yet, so there is no boot-time picture on any Alder Lake board in
  the tree. The OS driver brings up HDMI and DisplayPort normally. No VBT has
  been captured from this board, so `INTEL_GMA_HAVE_VBT` is not selected.
* **Fan control.** The `SYS_FAN` header is not driven. Which of the IT8625E's
  three fan channels it is wired to has not been established, and the stock
  firmware does not drive it either: it leaves SmartGuardian disabled and all
  three PWM outputs switched off.
* **M2_5G slot.** The M.2 Key-B WWAN slot has not been exercised. Its USB 2.0
  port index is assumed to be the one remaining unaccounted PCH port and is
  marked as unverified in the devicetree.

## Flash layout

```
FLASH 16M {
	SI_ALL 6M {
		SI_DESC		4K
		SI_ME
	}
	SI_BIOS 10M {
		RW_MRC_CACHE	64K
		SMMSTORE	512K
		FMAP		4K
		COREBOOT(CBFS)
	}
}
```

## Technology

| Component | Detail |
|-----------|--------|
| CPU | Intel N100 (Alder Lake-N) |
| PCH | Alder Lake-N, `8086:5481` |
| Super I/O | ITE IT8625E, config port `0x2e`, EC at `0x0a20` |
| Memory | 1x DDR5 SO-DIMM, 4800 MT/s |
| TPM | Intel PTT over the CRB interface at `0xfed40000` |
| Flash | 16 MiB SOIC-8 SPI, unlocked descriptor |
